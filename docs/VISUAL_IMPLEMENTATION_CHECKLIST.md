# Checklist de alineación visual

**Referencia primaria aprobada:** `mockup_marketplace.png`

**Referencia secundaria:** `mockup_bienestar.png`, solo para la transición emocional posterior al checkout falso.

Este checklist se extrajo de la inspección directa de ambos mockups antes de modificar la interfaz.

## Rasgos concretos de `mockup_marketplace.png`

- [ ] **Composición:** encabezado comercial compacto, zona de tiendas visible antes del catálogo y productos mostrados como contenido principal; el móvil concentra todo en una sola columna de secciones.
- [ ] **Header:** franja cálida de marca, logo/nombre a la izquierda, utilidades compactas a la derecha y un buscador visual integrado en el mockup. En el MVP no se añadirá búsqueda sin función: ese espacio se reinterpretará como mensaje breve de simulación.
- [ ] **Densidad:** varias tiendas y productos quedan visibles simultáneamente; se evita que una sola tarjeta ocupe casi toda la pantalla.
- [ ] **Espaciado:** separación corta entre elementos relacionados (8–12 px) y separación de sección moderada (20–24 px), sin grandes vacíos de hero.
- [ ] **Tarjetas:** tiendas pequeñas, casi cuadradas; productos verticales y compactos, con borde/sombra sutil. Radios aproximados de 10–16 px, no contenedores repetidos de 32 px.
- [ ] **Imágenes:** son el elemento dominante de tiendas y productos; deben ocupar alrededor de dos tercios de la tarjeta de producto y verse antes que la descripción.
- [ ] **Jerarquía tipográfica:** nombre de sección y precio con alto contraste; nombres y descripciones más pequeños; el precio se reconoce en un barrido rápido.
- [ ] **Navegación:** acceso persistente y compacto a inicio, tiendas/catálogo, carrito e historial. No se incorporan perfil, favoritos, ajustes ni notificaciones.
- [ ] **Tiendas y categorías:** tiendas como destinos visuales recorribles en tira/grid; categorías como navegación horizontal compacta, no como grandes tarjetas de bienestar.
- [ ] **Carrito:** icono/acción visible con badge de cantidad; el carrito usa líneas familiares con miniatura, cantidad, precio, eliminar y subtotal.
- [ ] **Mobile:** marca y estado en la parte superior, contenido de borde a borde con padding reducido, tiendas compactas y grid de dos productos por fila entre 360 y 430 px.
- [ ] **Desktop:** el mockup muestra sidebar y contenido amplio. El MVP conservará header superior y ampliará el grid, pero omitirá la sidebar porque sus destinos están fuera de alcance.
- [ ] **Color:** amarillo cálido dominante para navegación/acción, blanco cálido para superficies, tinta oscura para legibilidad y acentos coral/violeta/azul propios para categorías. Se evita replicar una marca real.

## Traducción aprobada a Carrito Fantasma

- [ ] Mantener visible el indicador compacto “Compra fantasma · sin cobro”.
- [ ] Home explica la simulación en menos de 10 segundos y prioriza “Comprar algo”; el rating inicial sigue opcional y secundario.
- [ ] Store selector y catálogo se sienten como exploración comercial, con identidad ficticia propia.
- [ ] Product detail prioriza imagen, nombre, precio, descripción corta y “Agregar al carrito fantasma”.
- [ ] Checkout conserva composición de resumen de pedido, pero nunca muestra campos de pago, dirección o identidad.
- [ ] Tracking inicia la transición desde el amarillo energético hacia fondos y acentos más calmados.
- [ ] Result e History reservan el lenguaje sereno para cierre, reflexión y ahorro real local.
- [ ] Evitar descuentos engañosos, stock, cuenta regresiva, reseñas falsas y elementos de marketplaces reales.
